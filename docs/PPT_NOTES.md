## Problem Statement SIH26263
> **"Development of an APAAR ID-Based Student Data Management and Verification Platform for AICTE-Approved Institutions"**

---

## 🏆 Executive Summary for Hackathon Judges
**APAAR Verify** is an enterprise-grade, privacy-first data management and verification platform tailored specifically for AICTE's network of technical institutions. Built using a modern **Spotify dark theme architecture**, the platform harmonizes **12-digit Luhn APAAR verification**, **unsupervised machine learning (IsolationForest) anomaly scoring**, **tamper-evident SHA-256 cryptographic audit hash chaining**, and **statutory DPDP Act 2023 compliance**.

## 🛠️ Technical Architecture & Differentiators

| Component | Technical Implementation | Value Delivered |
|---|---|---|
| **APAAR Luhn Checksum** | Custom modulus-10 check digit algorithm | Catches typo errors and fabricated IDs before API ingestion |
| **ML Anomaly Detection** | scikit-learn `IsolationForest` (contamination=0.04) | Flags subtle multi-variate statistical anomalies in academic metrics |
| **Tamper-Evident Chain** | SHA-256 hash chaining `H_n = SHA256(H_{n-1} + data)` | Guarantees immutability and instant detection of unauthorized DB tampering |
| **DigiLocker Mock Gateway** | Latency injection, rate-limiting (120 RPM), error modes | Simulates production government gateway with field-by-field diff matrix |
| **Field-Level Encryption** | Fernet AES-256 with secret salt | Guarantees Aadhaar and phone numbers cannot be leaked even in raw DB dumps |
| **PDF Generation** | ReportLab + qrcode vector QR generation | Issues tamper-verifiable credentials with public validation endpoints |
| **Realtime WebSockets** | Starlette / FastAPI WebSocket Manager | Pushes instant notification alerts to connected admin browsers |
